LEAD FINDER
===========

CARA MENJALANKAN
1. Pastikan Python 3 sudah terpasang di Windows.
2. Klik dua kali file JALANKAN.bat.
3. Saat pertama kali dijalankan, tunggu sampai paket yang diperlukan selesai dipasang.
4. Browser akan membuka http://127.0.0.1:5001.
5. Biarkan jendela hitam tetap terbuka selama aplikasi digunakan.
6. Untuk mematikan aplikasi, tutup jendela hitam tersebut.

FITUR
- Mengambil satu nomor telepon/WhatsApp dari teks, tautan, gambar (jika OCR tersedia), atau metadata halaman.
- Menampilkan pratinjau live. Sebagian website melarang tampilan di dalam panel; gunakan tombol Buka website di browser.
- Tombol Instagram tersedia jika tautan profil ditemukan. Login dan verifikasi dilakukan langsung di Instagram.
- Shortcut: I membuka Instagram, O membuka website, C menyalin nomor. Shortcut aktif saat kolom URL tidak sedang fokus.

CATATAN GAMBAR / OCR
Untuk membaca nomor yang tertulis dalam gambar, pasang Tesseract OCR untuk Windows secara terpisah. Jika belum dipasang, pencarian teks dan metadata tetap bekerja.

DATA DAN PRIVASI
Aplikasi berjalan lokal di komputer. Scraper mengakses URL yang dimasukkan untuk membaca informasi kontak publik. Gunakan data secara bertanggung jawab dan ikuti ketentuan website sumber. Status aktif WhatsApp tidak bisa dipastikan hanya dari nomor.
